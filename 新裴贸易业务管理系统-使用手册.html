10 分钟入门

首次登录，先完成这 4 步

目标：10 分钟内找到一条待办，读懂它的状态，并确认自己进入了正确的单据。

第 1 步

进入工作台

输入管理员提供的用户名和密码，点击 “登录”。看到页面标题 “工作台”，说明登录成功。

第 2 步

打开一条待办

在 “今日优先处理” 中先看逾期状态和截止时间，再点击任务右侧的 “去处理”。

第 3 步

判断能否操作

先看“状态”和“下一步”。草稿通常可以修改；待审批表示已经提交，不要重复建单。

第 4 步

核对单据

打开详情，核对单号、客户或供应商、负责人和日期。信息一致后关闭详情，返回原列表。

i
登录后缺少菜单

先记录账号和菜单名称，再联系管理员检查角色权限。不要借用其他人的账号操作。

岗位入口

选择岗位，查看工作入口

只需记住本岗位的主要入口。其他岗位通过待办和单据状态与你衔接。

菜单状态

确认哪些菜单可以使用

“可用”表示可以进入。“非主流程”和“暂缓”表示当前不开放，不属于页面故障。

  • 产品资料可用
  • 工厂资料可用
  • 客户资料可用
  • 合作伙伴、单证资料非主流程

订单 Workflow

  • 订单中心可用
  • 采购合同可用
  • 出口报价、出货明细非主流程

QC / 跟单

  • QC 中心可用
  • 我的 QC 任务可用
  • 跟单中心可用
  • 样品登记、打样管理、寄样管理非主流程

仓库

  • 入仓可用
  • 入库计划、出库计划、货物出库非主流程

财务经营

  • 财务摘要可用
  • 老板看板可用
  • 经营、收付、核销、报销等 10 个入口摘要内

系统与暂缓

  • MCP 接入可用
  • 组织管理非主流程
  • 采购询价、开票通知暂缓

页面操作

按页面查操作步骤

选择目标页面，再依次查看入口、核对项、操作步骤、完成标志和异常处理。

01工作台查看今天要处理的任务展开
从哪里进入

登录后自动进入；也可以点击左侧“工作台”。

先核对什么

查看“今日优先处理”中的逾期状态、截止时间和任务来源。

怎么操作
  1. 优先处理已逾期任务。
  2. 核对截止时间和来源。
  3. 点击“去处理”。
完成标志

系统进入对应业务页面，页面中的单号与待办一致。

遇到问题

无法进入时，记录任务标题和来源，联系管理员检查来源单据和权限。

02产品资料查询、核对或新增商品展开
从哪里进入

基础资料 → 产品资料

先核对什么

核对商品编号、中文名、英文名、海关编码和单位。

怎么操作
  1. 输入编号或名称。
  2. 点击“查询商品”。
  3. 点击“查看详情”。
  4. 确认不存在后再新增。
完成标志

目标商品出现在结果中，详情字段与业务资料一致。

遇到问题

清空条件后重新查询；新增失败时检查编号是否重复、必填项是否完整。

03工厂资料和客户资料维护往来单位和联系人展开
从哪里进入

基础资料 → 工厂资料或客户资料

先核对什么

核对编号、名称、国家或地区、联系人和启用状态。

怎么操作
  1. 按编号、名称或联系人查询。
  2. 打开“查看详情”。
  3. 核对订单或验货要求。
  4. 确认不存在后再新增。
完成标志

资料状态为“启用”，后续单据能够选择该客户或工厂。

遇到问题

后续单据选不到资料时，检查启用状态和当前账号的数据权限。

04订单中心查询合同并跟进审批展开
从哪里进入

订单 Workflow → 订单中心

先核对什么

核对合同号、客户、计划出运日、金额和审批状态。

怎么操作
  1. 输入合同号或客户。
  2. 选择审批状态。
  3. 点击“查询”。
  4. 点击“查看详情”。
完成标志

提交后状态变为“待审批”；审批通过后变为“已审批”。

遇到问题

已审批单据不要直接重建。需要更正时，按公司单据更正流程处理。

05采购合同从销售需求生成工厂订单展开
从哪里进入

订单 Workflow → 采购合同

先核对什么

核对来源、供应商、交货日、金额和 QC 负责人。

怎么操作
  1. 点击“从出口合同生成”。
  2. 选择已审批的出口合同。
  3. 选择供应商并核对信息。
  4. 提交审批。
完成标志

来源显示“出口合同生成”，审批通过后状态为“已审批”。

遇到问题

没有来源合同时，检查出口合同是否已审批；没有供应商时，先补齐工厂资料。

06QC 中心和我的 QC 任务执行查验并记录结果展开
从哪里进入

QC / 跟单 → 我的 QC 任务；主管查看全部任务时进入“QC 中心”。

先核对什么

核对 QC 单号、采购合同、供应商、负责人和排期。

怎么操作
  1. 查询目标任务。
  2. 打开“查看详情”。
  3. 开始查验。
  4. 记录结果和异常。
完成标志

状态为“已完成”，结果显示“通过”或“不通过”。

遇到问题

“我的 QC 任务”为空时，把 QC 单号发给主管检查负责人。

07跟单中心更新采购履约节点展开
从哪里进入

QC / 跟单 → 跟单中心

先核对什么

核对采购合同、供应商、整体状态、基准日和节点进度。

怎么操作
  1. 查询采购合同。
  2. 打开“查看详情”。
  3. 确认当前节点。
  4. 只更新已经完成的节点。
完成标志

节点进度增加，并显示本次完成时间和操作记录。

遇到问题

已审批合同没有跟单计划时，核对合同和供应商后再使用“配置/生成”。

08入仓确认到货并更新库存展开
从哪里进入

仓库 → 入仓

先核对什么

核对采购合同、供应商、数量、入库模式、日期和库位。

怎么操作
  1. 查询入库单或采购合同。
  2. 点击“生成/审批入库单”。
  3. 核对数量和库位。
  4. 提交审批。
完成标志

状态为“已审批”；正式入库数量计入可用库存。

遇到问题

数量、来源或库位不一致时停止审批，先核对实物和采购合同。

09财务摘要和老板看板查询经营数据并处理审批展开
从哪里进入

财务经营 → 财务摘要或老板看板

先核对什么

核对查询期间、单据状态、币种和数据范围。

怎么操作
  1. 选择财务业务入口。
  2. 设置日期和状态。
  3. 点击“查询”或“查询统计”。
  4. 需要审批时点击“去审批”。
完成标志

审批后待审批数量减少，单据状态同步更新。

遇到问题

金额为 0 时，先检查期间、币种，以及是否已有出运或收付记录。

操作安全

提交前，先核对来源和状态

核对来源和状态可以防止重复建单、修改错单和库存不准。以下规则适用于所有业务页面。

每次都要做

  • 新增前，分别用编号和名称查询一次。
  • 修改前，核对单号、客户或供应商以及状态。
  • 存在上游单据时，优先使用“从……生成”。
  • 提交前，核对日期、币种、数量和负责人。
  • 反馈问题时，附上页面标题和目标单号。

以下操作不要做

  • 列表为空时，不要直接重复新增。
  • 不要把“草稿”当成已生效单据。
  • 不要借用管理员账号绕过权限或审批。
  • 不要用备注代替客户、供应商或来源单字段。
  • 不要通过重复建单更正已审批单据。

常用词解释

先看懂这 10 个常用词

这些词用于判断单据能否修改、由谁处理，以及是否已经影响后续业务。

草稿
单据已保存但未提交审批，通常仍可修改，也尚未正式生效。
待审批
单据已提交，正在等待审批。此时不要重复创建相同单据。
已审批
审批已经通过，后续采购、QC 或入仓可以使用这张单据。
来源单
当前单据的上游依据。例如采购合同由出口合同生成，出口合同就是来源单。
回写
下游操作完成后，系统自动把结果更新到上游单据或汇总数据。
QC
质量检查。QC 任务记录负责人、排期、检查结果和整改情况。
跟单节点
采购履约中的一个步骤。“2/6”表示共 6 个节点，已完成 2 个。
可用库存
已经完成正式入库，可以用于后续业务的库存数量。
待检库存
货物已经到仓，但还没有完成检查，暂不能作为可用库存。
工厂与供应商
菜单使用“工厂资料”，合同和列表字段使用“供应商”。两者都指供货单位。

问题排查

遇到问题，先按现象排查

先完成对应检查。问题仍未解决时，把账号、页面标题、筛选条件和目标单号发给管理员。

看不到菜单

先确认入口是否标为“非主流程”或“暂缓”。若其他人能看到而你看不到，请联系管理员检查角色权限。

反馈信息：账号 + 菜单名称

搜索不到记录

清空状态、日期和客户或供应商条件，再用完整业务单号查询。仍找不到时，确认是否进入了正确页面。

先清空条件，再查完整单号

按钮不能点击

检查必填项、单据状态和账号权限；同时确认该功能是否标为“非主流程”或“暂缓”。

先看页面提示，再核对状态

概览数字不正确

先核对日期、状态、币种和数据范围。概览用于汇总，具体金额和数量以明细列表为准。

反馈信息：页面 + 条件 + 代表单号
