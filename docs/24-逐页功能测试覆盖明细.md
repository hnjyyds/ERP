# 逐页功能测试覆盖明细（2026-11-12）

## 使用说明

此清单覆盖42个注册页面，区分历史现场操作、接口证据、只读检查、离线模拟和未覆盖细节。**入口可打开不代表全部功能通过；未执行的业务写入没有补做。**确认问题见 [总报告](23-逐页功能与安全审查.md)。

- 历史UI/API：用户收紧风险边界前已执行的测试，本轮只整理已有证据。
- 只读：之后仅进行GET和源码核对。
- 离线：内存模拟，阻断真实网络/数据库。
- 未全验：只列待覆盖范围，不把既有单元测试或按钮可见性当作该功能已通过。

页面快照可能包含加载中的局部区域；它们是观察证据，不是视觉基准。接口脚本与浏览器自动请求的记录范围不同。
