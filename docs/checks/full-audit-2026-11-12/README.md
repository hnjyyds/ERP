# 审查证据说明

本目录为本地审查结果，不包含可对当前服务重放的审批、并发写入、权限变更或数据清理脚本，也不包含临时访问令牌。

## 证据分层

- `pages/`：42个页面的历史截图和语义快照，部分截图存在局部加载状态；不能用截图存在推断该页全部功能通过。
- `styles/`：样式修复后的12组桌面尺寸与截图。
- `db-money-evidence.json`：此前只读查询得到的测试账务聚合；不是本轮重新执行写入后的结果。
- `receipt-*`、`payment-concurrency.json`、`invoices-after-concurrency.json`：用户收紧风险边界前的测试记录。
- `readonly-filter-checks.json`：风险边界切换之后的8条GET对照结果。
- `request-summary.json`：394条脚本请求的脱敏索引，不含密码、令牌和完整原始请求响应。
- `operation-coverage.json`：278个操作的脚本证据范围；没有脚本请求证据不等于浏览器绝未调用。
- `safety-handoff.json`：历史37次201创建请求的清单及未回滚状态，不是独立业务记录数量。
- `safe-mock-results.json`、`safe-export-tests.log`：离线模拟的缺陷断言结果。
- `existing-test-inventory.json`、`backend-tests.log`：既有测试标题索引与后端581条通过结果。

## 只读模拟复现文件

`readonly-repros/` 下是不会被项目默认测试收集的审查副本，不是生产改动。

- `ui-hooks.repro.tsx`：四个React hook模拟，替换全部相关API，并将真实fetch设为抛错；每例还断言没有fetch调用。
- `vitest-config.repro.ts`：复用项目测试配置，只选择临时审查测试文件。
- `exports.repro.py`：三个导出断言，模拟仓库，仅处理内存数据；禁止网络和SQLite连接。

本次结果是前端4个、导出3个预期行为断言失败，分别重现深链跳转、旧响应覆盖、CSV公式前缀和导出截断。它们用于证明当前缺陷，**不能描述为7个通过用例**。临时前端配置/测试文件已从`frontend/`移除，未把失败用例加入默认CI。

历史前端384条、后端581条通过与上述缺陷同时成立：既有测试未覆盖这些情形。当前未做任何业务修复。

## 安全边界

继续阶段仅有只读接口和离线模拟。没有恢复业务审批、账务、库存、角色或账号变更，没有发送邮件、实际快递或银行转账。之前创建的测试记录保留，未在当前库删除、反向冲销或整体回滚。

原始可写测试脚本和临时备份未复制到本目录；继续阶段使用的临时HTTP助手已锁定GET，令牌文件已删除。后续若要测试写入行为，必须先准备与当前业务库隔离的环境，不应直接重放历史测试。
