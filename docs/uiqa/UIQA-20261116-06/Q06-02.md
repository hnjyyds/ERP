# Q06-02：发票登记以自由文本输入关联标识

P2；违反D02。版本 index-AfnHhFyf.js，当前系统管理员/超级管理员，路径 /finance/payments。

进入付款管理→发票登记。供应商标识、开票通知标识、采购合同标识均为可编辑普通文本框（readOnly=false，disabled=false），未提供通过已有业务名称/编号选择及回填的入口。业务名称/编号又是相邻独立输入，用户难以确保关联一致。

预期：通过业务名称或编号选择既有资料并带出对应内容，无需用户取得并手填内部标识。此结论仅针对界面契约，未提交表单，不推断后端是否校验关联。

证据：[1440表单](screenshots/payment-form-1440.png)、[重开稳定截图](screenshots/payment-all-fields-reopen.png)、[控件测量](payment-register-measure.json)。其他视口见 payment-form-1280、payment-form-390。

根因未定位；建议增加业务资料选择与回填，再按选择A→选择B→清空→取消重开复验。
