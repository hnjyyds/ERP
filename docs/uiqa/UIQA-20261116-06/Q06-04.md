# Q06-04：绿色状态文字未达到对比度目标

P3；违反B06；版本 index-AfnHhFyf.js。已验证商品列表“启用”和付款列表“已付清”。

前景 rgb(82,196,26)，背景 rgb(246,255,237)，文字opacity=1，按sRGB相对亮度计算为2.2056:1，低于检查表普通文字4.5:1目标。状态不是禁用控件。

证据：[商品稳定截图](screenshots/product-final.png)、[商品测量](product-list-final-measure.json)、[付款稳定截图](screenshots/payment-final.png)、[付款测量](payment-list-1440-measure.json)。测量包含颜色、祖先背景合成、字体和位置。

建议提高状态文字亮度差并复验所有已知使用位置；本轮没有把相同绿色组件推断为其他42页都已检查。出货“已审批”本轮测得约5.64:1，不列入同一失败。

- 复验：8080 三档商品“启用”、付款“已付清”实测前景 `rgb(23,96,60)`、背景 `rgb(246,255,237)`，对比度 **7.37:1**；证据 [fix-verification.json](fix-verification.json)。
