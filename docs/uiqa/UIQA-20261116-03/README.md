## 还剩什么

1. **已确认P3：Q02-R2。** 客户下拉的可视名称正确，但浏览器无障碍树中的两个option名称都是UUID，缺少客户名/编号。已关闭重开重复核实。详情见[缺陷记录](Q02-R2-客户选项可访问名称.md)。
2. **测试门禁待清理/核验。** 按用户提供的最新结果，402个用例通过但仍有6个未处理错误。本轮未重跑单元测试，未独立确认其基线归属；不将断言全过等同于无异常绿灯，也不声称这些错误由本次修改引入。
3. **已声明的能力缺口。** 修复文档注明`sales_user_id`/`period`尚未接入出货筛选。实际月度表无下钻按钮，点击月份不导航；本轮没有构造不存在的界面入口，不能把这项能力标通过，也不将其算作本次客户路径回归失败。
4. **原有未测范围仍在。** 其他角色、写入/上传/审批/资金库存权限流程、完整历史查询回放等未完成。上一轮22页114组是当时5174证据，本轮在8080仅对相关路径抽查，未重跑全套全站检查。
