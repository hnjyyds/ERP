# Q05-08：“导出全部商品”只导出当前页

P2，已确认，待修复。index-By6s5oGf.js，admin/超级管理员，2026-11-17。

前置：通过已授权的UIQA资料导入，使商品总数为21。没有选中任何商品，没有关键词筛选。

复现：选择每页20条，在第1页点击导出；再翻至第2页点击导出。按钮可访问名称均为“导出全部商品”，页面总数均为21。

实际下载：第1页CSV包含20条，第2页CSV只包含QA261112-P01这1条，文件内容与各自当前页一致。预期“全部”应包含当前范围全部21条；若产品设计只允许导出当前页，则应明确标注当前页及数量，并另给完整导出路径。

影响：导出结果缺少其他页记录；这是下载结果范围错误，不是数据库记录丢失。选中1条时导出1条的独立场景通过。页码切换、页大小改变和刷新后自动回到有效页也独立记录，不把它们误报失败。

检查项：A02/A03/F02/F05的导出子场景。

证据：[CSV范围对照](P01-export-scope-comparison.json)、[第1页文件](downloads/P01-all-size20-page1.csv)、[第2页文件](downloads/P01-all-size20-page2.csv)、[第2页截图](screenshots/P01-page2.png)、[第2页快照及按钮名称](P01-page2.txt)。

源码辅助定位：`frontend/src/app/pages/masterdata/ProductsPage.tsx`的`exportSelectedCsv`在没有选中项时导出`model.products`，当前值是已加载页面的数据；供修复定位，不代替实测文件对照。

修复复验：页大小20/50，第一页/第二页，有无关键词，有无跨页选择，核对文件记录集和界面声明范围；不要只检查下载成功提示。

三档复核：1440、1280、390的第二页“全部”导出均只有1条；每页50条时可导出21条，进一步确认范围随当前页数据变化。新增文件`P01-all-page2-1280.csv`、`P01-all-page2-390.csv`、`P01-all-size50.csv`均已独立CSV解析核对，完整记录集见范围对照JSON。
