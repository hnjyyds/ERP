# Q05-20：手机审计日期浮层左侧被裁出屏幕

级别P2；版本`index-By6s5oGf.js`；admin；`/system/audit-logs`；手机390×844；1440×900和1280×720对照。

操作：打开审计日期范围的开始日期。桌面和1280下两个日历面板可见。390下浮层仍宽576px，左边界x=-217，11月面板大部分在视口外；11月17日单元格x=-163到-127，无法直接点选。关闭后在手机尺寸重新打开仍复现，排除了仅由桌面缩放造成的过渡状态。

预期范围日历在手机可用区域内，开始/结束日期、月份导航可达。实际右侧12月面板可见，左侧11月及其月份导航被裁出屏幕。桌面范围筛选可操作，不代表手机浮层通过。

证据：[三档浮层/面板/日期格测量](P42-calendar-geometry.json)、[手机首次](screenshots/P42-calendar-390.png)、[手机关闭后重开](screenshots/P42-calendar-fresh-mobile.png)、[1440对照](screenshots/P42-calendar-1440.png)、[1280对照](screenshots/P42-calendar-1280.png)。桌面真实点击11月17日至17日已查询出该日审计，见[P42日期正例](P42-date-17-hit-inventory.json)。

关联C05/G01/G02。建议移动端使用单面板或纵向面板，并复核月份导航、日期范围选择、键盘与重置；不能只把超出部分隐藏。
