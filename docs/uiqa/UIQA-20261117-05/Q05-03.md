# Q05-03 导航分组普通文字对比度不足（P3）

版本index-By6s5oGf.js，已在商品、出货、付款页面的不同导航展开状态及1440/1280视口测量。导航分组为可操作的正常菜单，不是禁用控件。

代表性前景rgb(140,143,156)，背景rgb(247,248,250)，opacity1，对比度约3.03:1；展开分组白背景约3.22:1。未达到检查表B06普通文字4.5:1目标。不要把此前已修复的绿色状态标签与本问题混为一谈；绿色标签当前已达标。

证据：P01-list-1440-measure.json、P09-list-1440-measure.json、P24-list-1440-measure.json及对应截图；每个测量记录含文字、颜色、合成背景和位置。只引用实际可见的导航分组，不以品牌标识或被遮挡节点作为此结论依据。

建议统一调整正常导航分组文字颜色后，回归已知页面和手机导航展开布局。其他次级文案/placeholder的逐项对比度继续核对，不自动推为全部失败。

## 组织编辑表单的字段标签（PAGE-40）

编辑公司信息的“公司名称、英文名称、地址、电话、银行账号”等正常可用字段标签也使用`rgb(140,143,156)`，白底、opacity=1，字号约11.18px，对比度3.2188:1。三档均复核；不是被遮罩的后台文字，也不是禁用状态。

[1440测量](P40-company-edit-1440-measure.json)、[1280测量](P40-company-edit-1280-measure.json)、[390测量](P40-company-edit-390-measure.json)、[手机表单](screenshots/P40-company-edit-390.png)。新增测量明确记录可视范围、中心无遮挡、祖先opacity及禁用上下文，避免将模态窗背后的导航误计为当前可用文字。该问题与导航的低对比度同列跟踪，但修复需覆盖这类表单标签，不能只改侧栏。

组织权限窗口的普通说明和“配置角色”标签亦为3.2188:1；三档的可见无遮挡、非禁用文字测量见[P40权限1440](P40-permission-default-1440-measure.json)、[1280](P40-permission-default-1280-measure.json)、[390](P40-permission-default-390-measure.json)。这与公司信息标签使用相同灰色，但仍按独立父布局保留证据。
