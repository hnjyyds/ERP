# Q05-18：财务报表“来源下钻”只显示路由文字，无法进入来源单据

级别P2；版本`index-By6s5oGf.js`；admin；`/finance/reports`；1440×900、1280×720、390×844；只读。

操作：在水单使用明细点击BR-MWYV53行的“来源”，再在货款支付情况点击PR-PG3X2P行的“来源”。请求均成功，但页面仅追加“来源下钻”区，显示来源编号、内部类型码以及“入口：来源单据… /finance/receipts”或“/finance/payments”的纯文本。来源区域没有链接或按钮，URL始终停在报表，无法从这里打开对应单据。

预期下钻提供可点击或键盘访问的准确来源入口，定位到相应记录或带明确编号的查询结果。即使改成可点击的模块首页，也需保留当前来源对象，不能让用户重新寻找。

证据：[UI触发响应](P32-source-drilldown-network.json)、[来源区域三档结构](P32-drilldown-targets.json)、[水单来源](screenshots/P32-source-receipt.png)、[付款来源手机截图](screenshots/P32-drilldown-target-390.png)、[桌面](screenshots/P32-drilldown-target-1440.png)。响应只提供模块级target_path；浏览器实际区域links/buttons均为空。未更改接口或绕过前端。

关联F05/C08/A02。来源类型的内部码另并入Q05-14，不重复计缺陷。该问题不同于老板看板历史已记录的月度/业务员下钻缺口。
