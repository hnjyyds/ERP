路径：商品资料 → 设置列视图。先关闭旧浮层，再分别在1440×900、1280×720、390×844真实点击展开，等待菜单稳定后测量。

390手机下，各可用菜单项（中文名称、英文名称、海关编码、单位、状态、配件、恢复默认）的整行menuitem点击区域为103.125×32 CSS px。最末“恢复默认”位于y786–818，中心命中正常，未被窗口边缘裁切；但高度32小于文档30 G02要求的44。不是把文字或图标尺寸误当点击区域，测量对象为整个可点击菜单行。禁用的“编号”不计入可用目标失败。

预期：手机下实际点击区域至少44×44。实际影响：菜单可用，但相邻项较密，触摸目标未达项目规范。

证据：[三档menuitem测量](P01-column-menu-targets.json)、[手机真实展开截图](screenshots/P01-columns-open-real-390.png)。早期`P01-columns-open-390`是关闭态，不用作本问题证据。
