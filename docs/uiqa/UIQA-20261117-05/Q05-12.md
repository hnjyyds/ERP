# Q05-12：联系人主要标记的手机点击区域高度不足

P3，已确认，待修复。index-By6s5oGf.js，admin；供应商、客户、合作伙伴三个联系人表单均实际验证。

390×844下，“设为主要联系人”的关联label点击区域为270×18 CSS px，未达到G02的44px高度要求。1440/1280下标签高度也为18px。测量的是原生input.labels中包含说明文字的完整外层label，不是16×16的复选框图形或内部空label。

点击说明文字能切换，聚焦后按Space也能切换；完整AX树中的名称为“设为主要联系人”。这些功能子项正确，不能报成无标签或键盘不可用。保存前均恢复未选中，原主要联系人保持不变。

证据：[供应商探测](P02-contact-checkbox-probe.json)、[客户探测](P03-contact-checkbox-probe.json)、[伙伴探测](P04-contact-checkbox-probe.json)，及各页`Pxx-contact-checkbox-1280-measure.json`；[手机截图](screenshots/P02-contact-checkbox-390.png)。早期`Pxx-contact-targets.json`只取了最近的内部label，其16px记录不能代表整个文字点击范围，以本次原生labels及实际点击结果为准。

建议：扩展外层label的手机最小高度和内边距，保留正常图形尺寸及已有标签关联。未运行语音读屏，名称结论仅来自浏览器AX树。
