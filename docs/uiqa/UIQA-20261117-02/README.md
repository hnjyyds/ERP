## 回填回调修复（2026-11-17）

- 根因：`rc-select` 的 `onChange` 第二个参数是选项对象本身（`{value,label,description}`），不含 `data` 包装；`RemoteSelect` 只读取 `option.data`，导致调用方拿到 `null`，业务编号回填为空、ID 仍正确。
- 修复：`RemoteSelect` 在无 `data` 时直接使用原选项；新增“连续选择 A、B 均回传各自业务编号”的组件用例。
