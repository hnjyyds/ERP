# 前端体验修复清单（2026-11-12）

## 背景

本清单来自一次实际浏览器走查：浏览并点击了工作台、商品、供应商、客户、出口合同、采购合同、QC、入库、财务、收款、组织管理，以及相关新增弹窗、商品选择抽屉、通知和设置。

整体配色与基础框架已经统一，主要问题集中在四类：

1. 业务表单暴露内部 ID，业务人员不知道填什么。
2. 缺少基础资料时流程走到死路，必须退出表单再重新回来。
3. 同类合同的录入方式不同，用户换模块就要重新学习。
4. 操作位置、术语、空状态、统计区和信息密度不一致。

本文档按“高 → 中 → 低 → 视觉一致性”的顺序记录问题、修复方式与完成状态。状态只使用「待办」「已完成」两种。

## 修复明细

### UX-01 业务表单暴露内部 ID

**采购合同**

- 删除“工厂标识”“商品标识”“来源出口合同 ID”“来源明细 ID”等只读或手填 ID 字段。
- 采购员从手填姓名 + ID 改为人员下拉选择，选中后自动写入 ID 与姓名快照。
- 从出口合同生成采购合同时，出口合同从手填 ID 改为按合同号搜索选择。
- 商品明细只展示商品名称、编号、规格、型号、数量、单位、单价、金额、备注。

**入库单**

- 删除“仓库 ID”只读字段，只保留仓库选择。
- 删除“库位 ID”手填字段，只保留库位名称输入，库位 ID 由前端按名称生成并随请求提交。
- 列表与详情仍展示“仓库 / 库位”名称，不展示内部 ID。

### UX-02 缺少基础资料时的操作衔接

- 出口合同客户下拉：无客户时提供“新增客户”，新标签页打开客户资料页。
- 采购合同供应商下拉：无供应商时提供“新增供应商”，新标签页打开供应商资料页。
- 采购合同商品抽屉、出口合同商品抽屉：无匹配商品时提供“新增商品”，新标签页打开商品资料页。
- 新标签页打开基础资料，当前弹窗和已填写内容保持不变，完成建档后回到原标签页刷新下拉即可继续。

### UX-03 合同录入一致性

- 采购合同表单结构调整为：
  - 第一段：合同号、合同日期、工厂、采购员、QC 负责人、币种、交货日期、来源、付款条款、备注。
  - 第二段：商品明细表，支持“添加商品”批量选择、逐行修改数量/单位/单价/备注、删除行。
- 明细表列与出口合同保持一致：商品、规格/型号、数量、单位、单价、金额、操作。
- 提交前校验：至少一条明细；每条明细必须有商品名称、单位、数量大于 0、单价不小于 0。

### UX-04 弹窗底部操作

- 长表单统一使用 `.modal-actions` 固定底栏，带粘性定位和背景模糊。
- 取消按钮在左、主操作在右；采购合同不再使用表单末尾的裸按钮。

### UX-05 税率单位

- 商品新增/编辑弹窗中，税率、退税率输入框显示 `%` 后缀。
- 录入值按百分比理解：输入 `13` 保存为 `0.13`，输入 `9` 保存为 `0.09`。
- 打开编辑时把库中的小数转换为百分比展示，避免用户看到 `0.13` 不知道填 13 还是 0.13。

### UX-06 QC 筛选栏

- 首行保留：搜索、状态、结果、查询、重置、刷新、新增。
- “更多筛选”展开后显示：供应商、采购合同、负责人范围。
- 有高级筛选生效时，按钮显示数量标记，避免折叠后误以为没有筛选。

### UX-07 术语与标题

统一后的名称：

| 位置 | 统一名称 |
|---|---|
| 菜单 / 页面标题 / 列表标题 | 商品资料 |
| 新增动作 | 新增商品 |
| 菜单 / 页面标题 | 供应商资料 |
| 客户列表标题 | 客户资料 |
| 菜单 / 页面标题 | 出口合同 |
| 采购合同 | 采购合同 |

- 同步修改前端 `nav.page.*`、列表标题、导出文件名。
- 同步修改后端菜单种子与 Alembic 迁移，保证已经初始化的数据库也更新菜单名称。
- 英文使用 `Products` / `Suppliers` / `Export Contracts`，不再出现 `Factories`、`Order Center`。

### UX-08 空状态

- 新增统一 `ListEmptyState`：根据是否带筛选条件显示不同标题、说明和动作。
- 尚未建档：显示“还没有商品 / 供应商 / 合同”等说明，并提供新增按钮。
- 筛选无结果：显示“没有匹配的结果”，并提供清空筛选按钮。
- 覆盖范围：商品列表、供应商/客户列表、出口合同列表、采购合同列表、QC 任务列表、入库单列表。

### UX-09 工具图标

- 商品列表的导入、导出按钮由纯图标改为“图标 + 文字”。
- 列设置图标从滑杆改为列视图图标，辅助名称保持“设置列视图”。

### UX-10 统计区

- 删除商品页“已导出商品”统计，避免 0 值且口径不清。
- 统计条高度和字号下调，减少首屏占位。
- 当统计值全部为 0 时降低视觉权重，避免首屏只看到一排 0。

### UX-11 组织管理

- 默认主区域改为“用户管理”。
- “部门与角色”收进第二个页签。
- 公司信息保留为紧凑摘要，并提供编辑入口。
- 统一组织页字号：统计数字、说明文字、角色信息与全站列表页一致；角色卡片不再省略关键信息。

### UX-12 财务入口卡片

- 卡片栅格由四列改为三列，降低单卡信息密度。
- 说明文字限制为两行，指标只保留一个主数字与单位说明。

### UX-13 采购合同弹窗遮挡

- 操作按钮从表单内部移到 Ant Design `Modal` 的 `footer`，底栏不再覆盖内容区，商品表头保持完整可读。
- 表单区域单独滚动，底栏始终可见，关闭与保存位置固定。
- “付款条款”和“合同备注”合并为一行，并压缩表单行间距与顶部留白，让商品明细表在首屏更早出现。

### UX-14 QC 空列表文案

- 列表空状态使用独立的 `listEmptyTitle` / `listEmptyDescription`，不再与详情面板共用同一组文案。
- 空列表显示“还没有 QC 任务”，说明会从采购合同审批自动生成，也可手动新增。
- QC 详情面板在未选择任务时仍保留“请返回列表选择任务查看详情”，两处场景不再混淆。

### UX-15 水单录入客户字段

- “客户标识”改为客户搜索选择，支持按客户编号或名称检索。
- “客户名称”改为只读，选择客户后自动带出，不再需要手填。
- 付款人称为空时同步带出客户名称，减少重复录入。

## 遗留与边界

- 基础资料新增采用新标签页打开，未实现“弹窗内直接建档后回填”。原因是客户、供应商、商品字段较多，直接内嵌会形成复杂嵌套表单。
- 仓库、库位仍无独立主数据接口，库位 ID 由名称生成，属于当前阶段的兼容口径。
- 术语调整涉及已初始化数据库的菜单名称，通过 Alembic 迁移回填，不修改用户已有业务数据。
