## 已确认的边界遗漏

### UIR-04-B：恰好在今日零点结束的昨日事件仍计入今天（P2）

源码位置：[dashboard/services.py](../backend/app/modules/system/dashboard/services.py#L90)。`_overlaps_range` 的结束时间条件为 `ends_at >= start`。自然日已定义为 `[起, 止)`，但事件只与今天起点相接时仍返回真。

只调用纯函数、未连接业务数据库的复现：Asia/Shanghai，事件开始于 2026-11-12 23:00，结束于 2026-11-13 00:00；查询 11 月 13 日的自然日。期望不计入，实际返回 `True`。正常昨天、跨到今天 01:00、今天、明天四种情况均符合预期。

影响：午夜结束的事件会跨两个自然日计数。建议区间重叠采用结束时间严格晚于当日起点的条件，并补充这个边界用例。当前创建/更新校验要求结束时间晚于开始时间，不需要借此兼容零时长日程。

证据：[day-boundaries.json](checks/ui-fix-independent-2026-11-13/day-boundaries.json)。

## 扩展检查发现的界面问题

### UIR-09：手机样品登记底栏把“取消”挤出可见区域（P2）

复现：390×844 → 样品登记 → 新增样品 → 在表单内部滚至末尾。

实际：表单可用宽270px，三个按钮各最小宽108px，加上两个12px间距共348px，右对齐后“取消”按钮x=-18、宽108，中心点不能命中按钮，文字被裁掉。其余两个按钮位于x102和222，“按当前表单导入”文字换行。右上角关闭仍可用，因此不是完全无法退出。

源码线索：[sample-pages.css](../frontend/src/styles/sample-pages.css#L316) 的底栏间距与按钮 `min-width:108px` 缺少手机回退。建议手机底栏换行/分层，将次要导入动作移至独立行，并逐一核对按钮文字及中心命中区域，不仅检查document.scrollWidth。

证据：[截图](checks/ui-fix-independent-2026-11-13/sample-footer-390.png)、[位置与裁切祖先](checks/ui-fix-independent-2026-11-13/sample-footer.json)。

### UIR-10：供应商“主要联系人”复选框与文字上下错位（P3）

复现：390×844 → 供应商资料 → 新增供应商 → 滚到底部。

实际：复选框在x60/y605，高16px；外层标签成为宽270、高64px的单列Grid，复选框容器占第一行，文字在下一行，失去常见的“方框 + 相邻说明”结构。截图中两者关联不直观，还平白占用纵向空间。

源码线索：[TradingPartnerPage.tsx](../frontend/src/app/pages/masterdata/TradingPartnerPage.tsx#L1130) 使用外层`label.checkbox-label`包裹Ant Checkbox；[design-system-apply.css](../frontend/src/styles/design-system-apply.css#L243) 对普通表单label统一设为Grid，原有`flex-direction:row`无法在Grid上修复布局。建议使用Checkbox自身的文本内容结构，或对布尔字段明确恢复同一行布局，并避免嵌套label。相同组件可能影响客户资料，但本条定点证据只针对供应商。

证据：[截图](checks/ui-fix-independent-2026-11-13/supplier-checkbox-390.png)、[extra.json](checks/ui-fix-independent-2026-11-13/extra.json)。

### UIR-11：可用下拉框提示仍过浅（P3）

复现：新增采购合同 → 供应商、采购员、QC负责人三个未选择的下拉框。

实际：三个控件都未禁用，提示色仍为`rgba(0,0,0,0.25)`，白底合成约#BFBFBF、对比度约1.84:1，明显浅于已修复的商品搜索提示。不能将这几项归入禁用态豁免。

源码线索：[antd-and-login.css](../frontend/src/styles/antd-and-login.css#L134) 的修复选择器为`.ant-select-selection-placeholder`，当前DOM却使用`.ant-select-placeholder`。建议按实际Ant Design版本的节点/主题token覆盖正常态与禁用态，再测最终计算色。

证据：[截图](checks/ui-fix-independent-2026-11-13/purchase-placeholder-390.png)、[含类名、计算色与disabled状态的记录](checks/ui-fix-independent-2026-11-13/extra.json)。

### UIR-12：手机弹窗关闭按钮仍只有28px宽（P3）

实际：本轮11类弹窗在390px下，关闭按钮均为28×44px。商品工具图标按钮和导航已达到44px规格，但该共享入口没有同步，仍不符合仓库UI规范的移动端44px目标。

源码线索：[modal-quality.css](../frontend/src/styles/modal-quality.css#L82) 固定关闭按钮宽28px；移动端只增加高度，没有扩大宽度。建议保持图标尺寸不变，把实际可点击区域扩展到至少44×44px。样品关闭按钮本轮实际点击成功，问题是命中区域偏窄，不是功能失效。

证据：[33组表单测量](checks/ui-fix-independent-2026-11-13/forms.json)、[关闭按钮尺寸和命中记录](checks/ui-fix-independent-2026-11-13/sample-footer.json)。
